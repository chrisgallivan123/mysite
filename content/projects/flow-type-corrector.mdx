# 🧠 Flow Type Corrector

Flow metrics depend on accurate work item classification — but teams frequently misapply types. Features labeled as Defects, Technical Debt misclassified as Features, Risks overlooked. In early testing across multiple datasets, this LLM-powered validation pipeline surfaced up to 25% misclassified Flow Item Types. The Flow Type Corrector uses n8n and OpenAI to inspect work item text, detect misclassifications, and recommend corrections based on Flow Framework® best practices — so your Flow Metrics reflect reality, not categorization errors.

## Features

- **Misclassification Detection**: LLM-powered textual analysis identifies incorrectly applied Flow Item Types
- **11-Stage Validation Pipeline**: Production n8n workflow with batching, statistics, and schema enforcement
- **Confidence Scoring**: Every suggestion includes transparency on certainty for human review
- **Viz-Turbo Integration**: Outputs formatted for immediate visualization and comparative analysis

# Personal Site Starter (Next.js + MDX + Tailwind)

## Quick start
1. **Create repo**: push this folder to GitHub.
2. **Install**: `npm i` (or `pnpm i` / `yarn`).
3. **Dev**: `npm run dev` → http://localhost:3000
4. **Deploy**: Import repo in Vercel. Set custom domain.

## Authoring
- Add MDX files under `content/posts`, `content/frameworks`, `content/case-studies`, `content/projects`.
- Frontmatter supported: `title, date, excerpt, tags`

## Customize
- Edit copy in `components/Hero.tsx`
- Tweak colors in `tailwind.config.ts`
- Navigation in `app/layout.tsx`
